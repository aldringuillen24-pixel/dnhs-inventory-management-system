# Frontend Rules

- Use Laravel Blade for server-rendered views.
- Use Tailwind CSS for styling.
- Use Alpine.js for lightweight client-side interactions.
- Use Heroicons for interface icons.
- Do not introduce another CSS or UI framework unless explicitly requested.
- Follow the existing project UI design system.
- Maintain consistent spacing, typography, colors, borders, and component styles.
- Reuse existing Blade components whenever possible.
- Avoid duplicating UI components.
- Keep JavaScript logic focused and minimal.
- Do not place complex business logic inside Blade templates.
- Keep presentation logic separate from application logic.
- Ensure forms provide clear labels and validation feedback.
- Maintain accessible semantic HTML.
- Ensure interactive elements have appropriate accessible labels.
- Design desktop-first while maintaining responsive behavior.
- Do not redesign existing pages unless explicitly requested.
- Preserve existing UI behavior when modifying a component.
