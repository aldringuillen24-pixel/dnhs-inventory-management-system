# Git Rules

- Do not delete or overwrite existing work without explicit permission.
- Do not reset, revert, or discard user changes unless explicitly requested.
- Do not modify unrelated files.
- Keep commits focused on a single logical change.
- Use clear and descriptive commit messages.
- Check the current Git status before performing potentially destructive operations.
- Do not commit secrets, credentials, API keys, or environment files containing sensitive information.
- Do not modify the Git history unless explicitly requested.
- Review changed files before recommending a commit.
